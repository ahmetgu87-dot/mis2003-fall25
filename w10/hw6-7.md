# Homework Assignment: Exploring Vibe Coding Experience
**Assignment Duration:** 2 Weeks
**Total Points:** 20 points (counted as 2 homework assignments)

---

## Assignment Overview

In this assignment, you will explore the emerging paradigm of "vibe coding" - AI-powered development tools that go beyond simple code completion to provide a more conversational, context-aware coding experience. You will research different vibe coding tools, build a real project using one of them, and document your experience.

---

## Learning Objectives

By the end of this assignment, you will be able to:
- Identify and compare modern AI-powered coding tools
- Understand the distinction between code completion, copilots, and vibe coding tools
- Apply vibe coding tools to build a functional project
- Reflect critically on the strengths and limitations of AI-assisted development
- Properly document and share code on GitHub

---

## Assignment Tasks

### **Part 1: Research and Tool Identification**

Research and create a comprehensive list of vibe coding tools. Include at minimum:
- **Cursor** (AI-first code editor)
- **Windsurf** (Codeium's agentic IDE)
- **Replit Agent** (AI pair programmer)
- **v0.dev** (Vercel's AI UI generator)
- **Bolt.new** (StackBlitz's AI full-stack developer)

Add any other tools you discover during your research (GitHub Copilot Workspace, Lovable, etc.).

For each tool, document:
- Tool name and developer/company
- Primary features and capabilities
- Pricing model (free tier, subscription, etc.)
- Programming languages supported

### **Part 2: Comparative Analysis**

Write a **500-800 word analysis** explaining how vibe coding tools differ from:

**Traditional Code Completion:**
- How do they go beyond simple autocomplete?
- What additional context do they consider?

**GitHub Copilot:**
- How is the interaction model different?
- What additional capabilities do vibe coding tools offer?

**ChatGPT/Claude in a separate window:**
- How does integration into the IDE change the workflow?
- What are the advantages of context-aware, project-integrated AI?

Your analysis should include:
- Specific examples of workflows
- Pros and cons of each approach
- Your informed opinion on when each tool type is most appropriate

### **Part 3: Build a Project**

Choose **ONE** vibe coding tool and build a functional project. Select from one of these options (or propose your own with instructor approval):

**Project Options:**
1. **Tetris Game** - Classic falling blocks game with score tracking
2. **Todo List App** - Task management with add, edit, delete, and persistence
3. **Weather Dashboard** - App that fetches and displays weather data
4. **Personal Portfolio Website** - Responsive site showcasing your work
5. **Calculator App** - Scientific calculator with history
6. **Pomodoro Timer** - Productivity timer with customizable intervals
7. **Quiz App** - Multiple-choice quiz with score tracking

**Technical Requirements:**
- The project must be functional (fully working, not just a prototype)
- Must include at least 3-5 key features
- Code should be well-structured and readable
- Include a README.md with setup instructions
- Must work when cloned and run by others

### **Part 4: Experience Documentation**

Create a document (markdown file: `EXPERIENCE.md`) in your repository that includes:

1. **Tool Selection Justification** (1-2 paragraphs)
   - Why did you choose this tool?
   - What made it appealing for this project?

2. **Development Process** (2-3 paragraphs)
   - How did you use the tool throughout development?
   - What prompts or commands were most effective?
   - How many iterations did it take to get working code?

3. **Challenges and Solutions** (2-3 paragraphs)
   - What difficulties did you encounter?
   - How did the AI tool help (or not help) overcome them?
   - What did you have to fix or modify manually?

4. **Reflection** (2-3 paragraphs)
   - What surprised you about vibe coding?
   - How did it change your development workflow?
   - Would you use this tool for future projects? Why or why not?
   - How do you think this technology might impact software development?
